# sfc-3d

Arquivos 3D e texturas do configurador de produtos da San Francisco Center.
Servidos pelo jsDelivr: `https://cdn.jsdelivr.net/gh/<usuario>/sfc-3d@main/<caminho>`

- `pivot/modelo/` — Cadeira Pivot (GLB com Draco; malhas `madeira`, `tecido`, `latao`)
- `pivot/madeiras/` — Avelã M01, Castanho M02, Mocca M03, Nero Fosco M04, Nero Fosco Semibrilho M05
- `pivot/acabamentos/` — tecidos e couros CRN (TC 5xx)
- `pivot/palhas/` — Natural PN01, Bronze PN02, Preta PN03
